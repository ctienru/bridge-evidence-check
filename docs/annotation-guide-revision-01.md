How to read this file. Each row is one place where the annotator (Terri) rejected or edited a model candidate with a reason that cites a clause, wrote a reason no clause covers, changed a status after seeing the facts, or hit an open contract item. Every row ends with a `Decision:` cell for Terri (accept / reject / edit).

A row that changes a frozen label names the `expected.json` entry and needs `gold_version` 2 plus a `changes` entry with the clause id (P-05, R-01). Under the wording proposed below no frozen label changes; the rows marked **alt** say what would change if Terri takes the other reading.
